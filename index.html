About this demo

This site is the deployed, read-only view of the Week 3 admin dashboard from the AI Customer Calling Agent internship project. It mirrors the local Python dashboard: overview numbers, a filterable call list and a full text transcript per call.

What is real

  • The dashboard design and views follow the implemented Week 3 local dashboard.
  • The first call is the transcript captured from the real simulated demo run.
  • Analytics are calculated from the sample call records shown here.

What is not real

  • Customer names, orders and most calls are fictional sample data.
  • No telephony line, microphone or speech recognition is connected.
  • No audio is recorded or stored; call pages say so explicitly.
  • The sign-in is a client-side demo gate, not production authentication.
  • No client CRM or live database is connected to this static site.

Week 3 scope

Local SQLite CRM with customers, orders and interactions; a call log with transcripts and outcomes; analytics for escalation rate, intents and daily volume; and a password-protected local dashboard. Tested with 104 automated tests and 19 live HTTP checks.
